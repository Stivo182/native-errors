# native-errors

Библиотека OneScript для нормализации исключений встроенных объектов. Она
преобразует распознанную `ИнформацияОбОшибке` в структурированную ошибку пакета
[`errors`](https://github.com/Stivo182/oscript-errors) со стабильным машинным кодом.

Поддерживаются файловая система, процессы, потоки, JSON, XML, текст, двоичные
данные и HTTP, включая ошибки сети, прокси и TLS.

## Установка

```text
opm install native-errors
```

Требуется OneScript 2.0 или новее.

## Быстрый старт

```bsl
#Использовать errors
#Использовать native-errors

Классификатор = Новый КлассификаторНативныхОшибок;

Попытка
    Чтение = Новый ЧтениеJSON;
    Чтение.Прочитать();
Исключение
    Ошибка = Классификатор.Классифицировать(ИнформацияОбОшибке());
    Если Ошибка <> Неопределено Тогда
        Сообщить(ДиагностикаОшибок.КодОшибки(Ошибка));
    КонецЕсли;
КонецПопытки;
```

Если исходная ошибка уже нормализована, классификатор возвращает тот же объект.
Если подходящее правило не найдено, возвращается `Неопределено`.

## Autumn

В Autumn [`КлассификаторНативныхОшибок`](docs/КлассификаторНативныхОшибок.md)
доступен как желудь.

## Расширение

Пользовательский классификатор должен предоставлять экспортный метод
`Классифицировать(Ошибка, Распознаватель)`. Он возвращает нормализованную ошибку
или `Неопределено`. Пользовательские классификаторы выполняются раньше
встроенных и в порядке добавления.

```bsl
Классификатор = Новый КлассификаторНативныхОшибок;
Классификатор.ДобавитьПользовательскийКлассификатор(Новый МойКлассификатор);
```

Для декларативных правил используйте
`ДобавитьПравила(МассивПравил)`. Правило описывается классом
[`ПравилоКлассификацииНативныхОшибок`](docs/ПравилоКлассификацииНативныхОшибок.md);
создавайте его через
[`ФабрикаПравилНативныхОшибок`](docs/ФабрикаПравилНативныхОшибок.md).
