# native-errors

Библиотека OneScript для нормализации исключений встроенных объектов. Она
преобразует распознанную `ИнформацияОбОшибке` в структурированную ошибку пакета
[`errors`](https://github.com/Stivo182/oscript-errors) со стабильным машинным кодом.

Поддерживаются файловая система, потоки, JSON, XML, текст, двоичные данные и
HTTP, включая ошибки сети, прокси и TLS.

## Установка

```text
opm install native-errors
```

Требуется OneScript 2.0 или новее. Пакет `errors` устанавливается как зависимость.

## Быстрый старт

```bsl
#Использовать native-errors
#Использовать errors

Классификатор = Новый КлассификаторНативныхОшибок;

Попытка
    Чтение = Новый ЧтениеJSON;
    Чтение.Прочитать();
Исключение
    НормализованнаяОшибка = Классификатор.Классифицировать(ИнформацияОбОшибке());

    Если НормализованнаяОшибка <> Неопределено Тогда
        Код = ДиагностикаОшибок.КодОшибки(НормализованнаяОшибка);
        Сообщить(Код);
    Иначе
        ВызватьИсключение;
    КонецЕсли;
КонецПопытки;
```

Если исходная ошибка уже нормализована, классификатор возвращает тот же объект.
Если подходящее правило не найдено, возвращается `Неопределено`.

## Autumn

Конструктор `КлассификаторНативныхОшибок` помечен `&Желудь`. В приложении
Autumn класс регистрируется как желудь с именем
`КлассификаторНативныхОшибок` и по умолчанию создаётся один раз.

## Расширение

Пользовательский классификатор должен предоставлять экспортный метод
`Классифицировать(Ошибка, Распознаватель)`. Он возвращает нормализованную ошибку
или `Неопределено`. Пользовательские классификаторы выполняются раньше
встроенных и в порядке добавления.

```bsl
Классификатор = Новый КлассификаторНативныхОшибок;
Классификатор.ДобавитьКлассификатор(Новый МойКлассификатор);
```

После настройки экземпляр можно использовать для параллельной классификации.
Не добавляйте классификаторы одновременно с вызовами `Классифицировать()`.
