# ФабрикаПравилНативныхОшибок

Создает [`ПравилоКлассификацииНативныхОшибок`](ПравилоКлассификацииНативныхОшибок.md)
для конкретного способа
сопоставления. Неиспользуемые параметры правила фабрика заполняет сама.
Текстовые параметры принимают обычную строку или шаблон `НСтр`.

## Методы

### Точное

```bsl
ФабрикаПравилНативныхОшибок.Точное(<ШаблонСообщения>, <КодОшибки>, <Сообщение>)
```

Создает правило точного сопоставления сообщения.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| ШаблонСообщения | `Строка` | Полное сообщение. |
| КодОшибки | `Строка` | Машинный код результата. |
| Сообщение | `Строка` | Нормализованное сообщение. |

#### Возвращаемое значение

[`ПравилоКлассификацииНативныхОшибок`](ПравилоКлассификацииНативныхОшибок.md).
