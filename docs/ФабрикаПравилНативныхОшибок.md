# ФабрикаПравилНативныхОшибок

Создаёт [`ПравилоКлассификацииНативныхОшибок`](ПравилоКлассификацииНативныхОшибок.md)
для конкретного способа
сопоставления. Неиспользуемые параметры правила фабрика заполняет сама.

## Методы

### Точное

```bsl
ФабрикаПравилНативныхОшибок.Точное(<ШаблонСообщения>, <КодОшибки>, <Сообщение>)
```

Создаёт правило точного сопоставления сообщения.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| ШаблонСообщения | `Строка` | Полное сообщение или шаблон `НСтр`. |
| КодОшибки | `Строка` | Машинный код результата. |
| Сообщение | `Строка` | Нормализованное сообщение или шаблон `НСтр`. |

#### Возвращаемое значение

[`ПравилоКлассификацииНативныхОшибок`](ПравилоКлассификацииНативныхОшибок.md).
