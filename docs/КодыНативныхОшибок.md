# КодыНативныхОшибок

Модуль `КодыНативныхОшибок` возвращает стабильные строковые коды. Используйте
его функции вместо строковых литералов при сравнении и создании ошибок.

```bsl
Если ДиагностикаОшибок.КодОшибки(Ошибка) = КодыНативныхОшибок.JSONНекорректныйСинтаксис() Тогда
    Сообщить("JSON содержит синтаксическую ошибку");
КонецЕсли;
```

Текст исходного исключения обычно содержит обёртку `Внешнее исключение` или
`External exception` с .NET-типом. В колонке «Сигнатура исходной ошибки» указаны
тип и точный текст, его начало, окончание или фрагмент, по которым выполняется
распознавание. `<...>` обозначает переменную часть сообщения.

| Группа | Функция | Значение | Описание | Сигнатура исходной ошибки |
| --- | --- | --- | --- | --- |
| Файловая система | `ФайловаяСистемаРесурсНеНайден()` | `filesystem.not_found` | Файл или каталог отсутствует. | `System.IO.FileNotFoundException` или `System.IO.DirectoryNotFoundException` |
|  | `ФайловаяСистемаРесурсУжеСуществует()` | `filesystem.already_exists` | Создаваемый файл уже существует. | `System.IO.IOException`: `Файл '<...>' уже существует.` / `The file '<...>' already exists.` |
|  | `ФайловаяСистемаРесурсЗанят()` | `filesystem.resource_busy` | Файл занят другим процессом или операцией. | `System.IO.IOException`: `Процесс не может получить доступ к файлу '<...>'...` / `The process cannot access the file '<...>'...` |
|  | `ФайловаяСистемаДоступЗапрещен()` | `filesystem.permission_denied` | Нет прав для операции с файлом или каталогом. | `System.UnauthorizedAccessException` |
| JSON | `JSONНекорректныйСинтаксис()` | `json.invalid_syntax` | Синтаксис JSON некорректен. | Начало `Недопустимое состояние потока чтения JSON в строке` / `Invalid JSON reader state at line` |
|  | `JSONЧтениеНеОткрыто()` | `json.reader_not_open` | Чтение выполняется до открытия источника. | `Источник данных JSON не открыт` / `JSON data source is not opened` |
|  | `JSONЗаписьНеОткрыта()` | `json.writer_not_open` | Запись выполняется до открытия приёмника. | `Приемник данных JSON не открыт` / `JSON data target is not opened` |
|  | `JSONТекущееЗначениеНедоступно()` | `json.value_unavailable` | Текущее значение `ЧтенияJSON` недоступно. | `Текущее значение JSON не может быть получено` / `Cannot get current JSON value` |
|  | `JSONНеподдерживаемыйТипЗначения()` | `json.unsupported_value_type` | Значение не поддерживается `ЗаписьюJSON`. | `Запись значения типа <...> не поддерживается` / `Cannot write value of type <...>` |
| XML | `XMLНекорректныйСинтаксис()` | `xml.invalid_syntax` | Синтаксис XML некорректен. | `System.Xml.XmlException` |
|  | `XMLЗаписьНеОткрыта()` | `xml.writer_not_open` | Запись выполняется до открытия приёмника. | `Приемник данных XML не открыт` / `XML data target is not opened` |
|  | `XMLНекорректноеСостояниеЗаписи()` | `xml.invalid_write_state` | Выполнена недопустимая операция `ЗаписиXML`. | `Ошибочный порядок записи XML` / `Wrong order of XML record` |
| Двоичные данные | `ДвоичныеДанныеНекорректныйHex()` | `binary.invalid_hex` | Hex-строка имеет неверный формат. | `System.FormatException`: `Неверный формат шестнадцатеричной строки` / `Invalid hexadecimal string format` |
|  | `ДвоичныеДанныеВыходЗаГраницыБуфера()` | `binary.buffer_out_of_bounds` | Операция выходит за границы двоичного буфера. | `System.IndexOutOfRangeException`: `Переполнение при работе с буфером` / `Buffer overflow`; также ошибки длины массива |
|  | `ДвоичныеДанныеТолькоДляЧтения()` | `binary.read_only` | Выполнена попытка изменить буфер только для чтения. | `Буфер находится в режиме "Только чтение"` / `Buffer is read-only` |
| Текст | `ТекстНеизвестнаяКодировка()` | `text.unknown_encoding` | Указана неизвестная текстовая кодировка. | Начало `Неправильное имя кодировки` / `Invalid encoding name`; либо `System.ArgumentException` с окончанием `is not a supported encoding name...` |
|  | `ТекстНеОткрыт()` | `text.not_open` | Чтение или запись выполняется до открытия объекта. | `Файл не открыт` / `File is not open` |
| Потоки | `ПотокЗакрыт()` | `stream.closed` | Операция выполняется с закрытым потоком. | `Ошибка обращения к закрытому потоку` / `Cannot access a closed stream`; либо `System.ObjectDisposedException` |
|  | `ПотокНеПоддерживаетЗапись()` | `stream.not_writable` | Поток не поддерживает запись. | `Попытка записи в поток не поддерживающий запись` / `Cannot write to a stream that does not support writing` |
|  | `ПотокВыходЗаГраницыБуфера()` | `stream.buffer_out_of_bounds` | Диапазон буфера выходит за границы операции с потоком. | `System.ArgumentOutOfRangeException`: `Смещение и длина находились вне границ массива.` |
| HTTP | `HTTPТаймаутЗапроса()` | `http.request_timeout` | Истекло время HTTP-запроса. | `System.Net.WebException`: `Время ожидания операции истекло.` / `The operation has timed out.` |
|  | `HTTPНекорректныйМетод()` | `http.invalid_method` | HTTP-метод имеет некорректный формат. | `System.ArgumentException`: `Cannot set null or blank methods on request. (Parameter 'value')` |
|  | `HTTPНекорректныйЗаголовок()` | `http.invalid_header` | HTTP-заголовок имеет некорректный формат. | `Заголовок <Content-Length, Date, If-Modified-Since, Range> задан неправильно` / `Header <...> is invalid`; также ограниченные заголовки .NET |
|  | `HTTPНекорректныйОтвет()` | `http.invalid_response` | Структура HTTP-ответа нарушена. | `System.Net.WebException`: начало `Received an invalid status line:`, `Received an invalid status code:` и другие варианты некорректного заголовка или chunk |
|  | `HTTPНеполныйОтвет()` | `http.incomplete_response` | Тело HTTP-ответа оборвано преждевременно. | `System.Net.Http.HttpIOException`: `The response ended prematurely... (ResponseEnded)` |
|  | `HTTPПользовательскоеTLSНеПоддерживается()` | `http.custom_tls_unsupported` | Передача пользовательских TLS-сертификатов не поддерживается. | `Защищенное соединение по произвольным сертификатам не поддерживается...` |
| Прокси | `ПроксиТребуетсяАутентификация()` | `proxy.authentication_required` | HTTPS-прокси требует аутентификации. | `System.Net.WebException`, фрагмент `failed with status code '407'` |
|  | `ПроксиТуннельНеУстановлен()` | `proxy.tunnel_failed` | HTTPS-прокси не создал туннель. | `System.Net.WebException`, фрагмент `The proxy tunnel request to proxy` |
| Сеть | `СетьИмяУзлаНеРазрешено()` | `network.name_resolution_failed` | Не удалось разрешить сетевое имя. | `System.Net.Sockets.SocketException`: `Этот хост неизвестен.` / `No such host is known.` |
|  | `СетьСоединениеОтклонено()` | `network.connection_refused` | Удалённый узел отклонил соединение. | `System.Net.Sockets.SocketException`: начало `Подключение не установлено...` / `No connection could be made because...` |
|  | `СетьСоединениеСброшено()` | `network.connection_reset` | Удалённый узел принудительно сбросил соединение. | `System.Net.Sockets.SocketException`: `Удаленный хост принудительно разорвал...` / `An existing connection was forcibly closed...` |
|  | `СетьОшибкаTLSHandshake()` | `network.tls_handshake_failed` | Не удалось установить защищённое TLS-соединение. | `System.Net.WebException`: `The SSL connection could not be established, see inner exception.` |

Наличие кода в модуле не является обещанием, что любая ошибка с таким смыслом
будет распознана: классификация зависит от поддерживаемых встроенных объектов и
текста исключения OneScript.
