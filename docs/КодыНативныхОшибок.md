# КодыНативныхОшибок

Модуль `КодыНативныхОшибок` возвращает стабильные строковые коды. Используйте
его функции вместо строковых литералов при сравнении и создании ошибок.

```bsl
Если ДиагностикаОшибок.КодОшибки(Ошибка) = КодыНативныхОшибок.JSONНекорректныйСинтаксис() Тогда
    Сообщить("JSON содержит синтаксическую ошибку");
КонецЕсли;
```

| Группа | Функция | Значение | Описание |
| --- | --- | --- | --- |
| Файловая система | `ФайловаяСистемаРесурсНеНайден()` | `filesystem.not_found` | Файл или каталог отсутствует. |
|  | `ФайловаяСистемаРесурсУжеСуществует()` | `filesystem.already_exists` | Создаваемый файл уже существует. |
|  | `ФайловаяСистемаРесурсЗанят()` | `filesystem.resource_busy` | Файл занят другим процессом или операцией. |
|  | `ФайловаяСистемаДоступЗапрещен()` | `filesystem.permission_denied` | Нет прав для операции с файлом или каталогом. |
| JSON | `JSONНекорректныйСинтаксис()` | `json.invalid_syntax` | Синтаксис JSON некорректен. |
|  | `JSONЧтениеНеОткрыто()` | `json.reader_not_open` | Чтение выполняется до открытия источника. |
|  | `JSONЗаписьНеОткрыта()` | `json.writer_not_open` | Запись выполняется до открытия приёмника. |
|  | `JSONТекущееЗначениеНедоступно()` | `json.value_unavailable` | Текущее значение `ЧтенияJSON` недоступно. |
|  | `JSONНеподдерживаемыйТипЗначения()` | `json.unsupported_value_type` | Значение не поддерживается `ЗаписьюJSON`. |
| XML | `XMLНекорректныйСинтаксис()` | `xml.invalid_syntax` | Синтаксис XML некорректен. |
|  | `XMLЗаписьНеОткрыта()` | `xml.writer_not_open` | Запись выполняется до открытия приёмника. |
|  | `XMLНекорректноеСостояниеЗаписи()` | `xml.invalid_write_state` | Выполнена недопустимая операция `ЗаписиXML`. |
| Двоичные данные | `ДвоичныеДанныеНекорректныйHex()` | `binary.invalid_hex` | Hex-строка имеет неверный формат. |
|  | `ДвоичныеДанныеВыходЗаГраницыБуфера()` | `binary.buffer_out_of_bounds` | Операция выходит за границы двоичного буфера. |
|  | `ДвоичныеДанныеТолькоДляЧтения()` | `binary.read_only` | Выполнена попытка изменить буфер только для чтения. |
| Текст | `ТекстНеизвестнаяКодировка()` | `text.unknown_encoding` | Указана неизвестная текстовая кодировка. |
|  | `ТекстНеОткрыт()` | `text.not_open` | Чтение или запись выполняется до открытия объекта. |
| Потоки | `ПотокЗакрыт()` | `stream.closed` | Операция выполняется с закрытым потоком. |
|  | `ПотокНеПоддерживаетЗапись()` | `stream.not_writable` | Поток не поддерживает запись. |
|  | `ПотокВыходЗаГраницыБуфера()` | `stream.buffer_out_of_bounds` | Диапазон буфера выходит за границы операции с потоком. |
| HTTP | `HTTPТаймаутЗапроса()` | `http.request_timeout` | Истекло время HTTP-запроса. |
|  | `HTTPНекорректныйМетод()` | `http.invalid_method` | HTTP-метод имеет некорректный формат. |
|  | `HTTPНекорректныйЗаголовок()` | `http.invalid_header` | HTTP-заголовок имеет некорректный формат. |
|  | `HTTPНекорректныйОтвет()` | `http.invalid_response` | Структура HTTP-ответа нарушена. |
|  | `HTTPНеполныйОтвет()` | `http.incomplete_response` | Тело HTTP-ответа оборвано преждевременно. |
|  | `HTTPПользовательскоеTLSНеПоддерживается()` | `http.custom_tls_unsupported` | Передача пользовательских TLS-сертификатов не поддерживается. |
| Прокси | `ПроксиТребуетсяАутентификация()` | `proxy.authentication_required` | HTTPS-прокси требует аутентификации. |
|  | `ПроксиТуннельНеУстановлен()` | `proxy.tunnel_failed` | HTTPS-прокси не создал туннель. |
| Сеть | `СетьИмяУзлаНеРазрешено()` | `network.name_resolution_failed` | Не удалось разрешить сетевое имя. |
|  | `СетьСоединениеОтклонено()` | `network.connection_refused` | Удалённый узел отклонил соединение. |
|  | `СетьСоединениеСброшено()` | `network.connection_reset` | Удалённый узел принудительно сбросил соединение. |
|  | `СетьОшибкаTLSHandshake()` | `network.tls_handshake_failed` | Не удалось установить защищённое TLS-соединение. |

Наличие кода в модуле не является обещанием, что любая ошибка с таким смыслом
будет распознана: классификация зависит от поддерживаемых встроенных объектов и
текста исключения OneScript.
