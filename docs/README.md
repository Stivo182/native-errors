# Документация API

Пакет `native-errors` нормализует исключения встроенных объектов OneScript.
Он преобразует распознанные ошибки в структурированные ошибки пакета `errors` со
стабильными машинными кодами.

## Руководство

- [Публичный интерфейс](ПубличныйИнтерфейс.md) - подключение пакета, быстрый
  старт и состав API.
- [КлассификаторНативныхОшибок](КлассификаторНативныхОшибок.md) -
  классификация встроенных исключений и пользовательские классификаторы.
- [РаспознавательЦепочкиОшибок](РаспознавательЦепочкиОшибок.md) - поиск в
  цепочке причин и двуязычные шаблоны сообщений.
- [КодыНативныхОшибок](КодыНативныхОшибок.md) - полный каталог стабильных
  машинных кодов.

## Публичные классы

- `КлассификаторНативныхОшибок` - фасад классификации и точка расширения.
- `РаспознавательЦепочкиОшибок` - индексированный поиск типов и сообщений в
  цепочке исключений.

## Публичные модули

- `КодыНативныхОшибок` - функции, возвращающие именованные машинные коды.
