# ПравилоКлассификацииНативныхОшибок

Описывает декларативное правило для
[`КлассификаторНативныхОшибок.ДобавитьПравила()`](КлассификаторНативныхОшибок.md).

Для обычного создания правила используйте
[`ФабрикаПравилНативныхОшибок`](ФабрикаПравилНативныхОшибок.md): она оставляет
в вызове только параметры выбранного способа сопоставления.

## Создание

```bsl
Новый ПравилоКлассификацииНативныхОшибок(
    <Способ>,
    <НативныйТип>,
    <Начало>,
    <Окончание>,
    <КодОшибки>,
    <Сообщение>
)
```

## Пример

Если текст ошибки содержит изменяемые детали, используйте фрагмент вместе с
нативным типом:

```bsl
Классификатор = Новый КлассификаторНативныхОшибок;

Правила = Новый Массив;
Правила.Добавить(ФабрикаПравилНативныхОшибок.ТипИФрагмент(
    "System.Net.Sockets.SocketException",
    НСтр("ru = 'Отказано в подключении'; en = 'Connection refused'"),
    "application.backend_unavailable",
    НСтр("ru = 'Сервер приложения недоступен'; en = 'Application server is unavailable'")
));

Классификатор.ДобавитьПравила(Правила);
```

`ТипИФрагмент()` требует, чтобы тип `System.Net.Sockets.SocketException` и
текстовый фрагмент находились в одном кадре ошибки. Поэтому общее выражение
`Connection refused` не сработает в ошибке другого типа.

## Параметры конструктора и поля

| Имя | Тип | Описание |
| --- | --- | --- |
| Способ | Число | Идентификатор из модуля [`СпособыСопоставленияНативныхОшибок`](СпособыСопоставленияНативныхОшибок.md). Определяет, какие поля участвуют в проверке. |
| НативныйТип | Строка | Полное имя .NET-типа из внешнего исключения, например `System.IO.IOException`. Используется только способами с проверкой типа. Для остальных способов передавайте пустую строку. |
| Начало | Строка | Текст для проверки сообщения: полное сообщение, его префикс или фрагмент в зависимости от `Способ`. Для двуязычных правил допустим шаблон `НСтр` с вариантами `ru` и `en`. |
| Окончание | Строка | Завершающая часть сообщения для способов с окончанием. Для остальных способов передавайте пустую строку. Поддерживает шаблон `НСтр`. |
| КодОшибки | Строка | Машинный код результата. Для пользовательского правила это может быть собственный стабильный код приложения; он не обязан входить в [`КодыНативныхОшибок`](КодыНативныхОшибок.md). |
| Сообщение | Строка | Текст нормализованной ошибки. Сохраняется в её описании вместо исходного текста. Поддерживает шаблон `НСтр`. |

## Использование полей способами сопоставления

| Способ | НативныйТип | Начало | Окончание |
| --- | --- | --- | --- |
| `Точное()` | Не используется | Полное совпадение сообщения. | Не используется. |
| `Префикс()` | Не используется | Сообщение должно начинаться с значения. | Не используется. |
| `ПрефиксОкончание()` | Не используется | Сообщение должно начинаться с значения. | Сообщение должно оканчиваться значением. |
| `ПоТипу()` | Точное совпадение типа. | Не используется. | Не используется. |
| `ТипИОкончание()` | Точное совпадение типа. | Не используется. | Сообщение должно оканчиваться значением. |
| `ТипИФрагмент()` | Точное совпадение типа. | Сообщение должно содержать значение. | Не используется. |
| `ТипИОбрамление()` | Точное совпадение типа. | Сообщение должно содержать значение. | Сообщение должно оканчиваться значением. |

Если в `Начало` или `Окончание` передан двуязычный шаблон, значения полей
проверяются в одном варианте языка.
