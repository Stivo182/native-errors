## Создание

```bsl
Новый РаспознавательЦепочкиОшибок(<Ошибка>)
```

Экземпляр индексирует ошибку при создании. Шаблоны сообщений принимают обычную
строку или двуязычный шаблон `НСтр` с вариантами `ru` и `en`.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Ошибка | `ИнформацияОбОшибке` | Исходная ошибка для последующих проверок. |

## Методы

### СодержитТип

```bsl
.СодержитТип(<НативныйТип>)
```

Проверяет наличие .NET-типа в цепочке причин.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| НативныйТип | `Строка` | Полное имя .NET-типа. |

#### Возвращаемое значение

`Булево`: `Истина`, если тип найден.

### НайтиТип

```bsl
.НайтиТип(<НативныеТипы>)
```

Находит первый тип из переданного списка.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| НативныеТипы | `Массив` из `Строка` | Полные имена .NET-типов в порядке приоритета. |

#### Возвращаемое значение

`Строка` с найденным типом либо `Неопределено`.

### СодержитТочноеСообщение

```bsl
.СодержитТочноеСообщение(<ШаблонСообщения>)
```

Проверяет точное совпадение сообщения в цепочке причин.

#### Параметры

| --- | --- | --- |
| ШаблонСообщения | `Строка` | Сообщение или двуязычный шаблон `НСтр`. |

#### Возвращаемое значение

## Подробное представление ошибки

Распознаватель поддерживает текст, полученный через
`ПодробноеПредставлениеОшибки(ИнформацияОбОшибке())`.

По возможности передавайте исходный объект `ИнформацияОбОшибке()`: так
классификация будет точнее.
