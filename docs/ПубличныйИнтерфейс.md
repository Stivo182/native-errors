# Публичный интерфейс

Пакет `native-errors` преобразует ошибки встроенных объектов OneScript в
структурированные ошибки пакета [`errors`](https://github.com/Stivo182/oscript-errors). Машинный код результата можно получать
через `ДиагностикаОшибок.КодОшибки(<Ошибка>)`.

Подключение в прикладном модуле:

```bsl
#Использовать errors
#Использовать native-errors

Классификатор = Новый КлассификаторНативныхОшибок;

Попытка
    Чтение = Новый ЧтениеJSON;
    Чтение.Прочитать();
Исключение
    Ошибка = Классификатор.Классифицировать(ИнформацияОбОшибке());
    Если Ошибка <> Неопределено Тогда
        Сообщить(ДиагностикаОшибок.КодОшибки(Ошибка));
    КонецЕсли;
КонецПопытки;
```

Ошибка с кодом из [`КодыНативныхОшибок`](КодыНативныхОшибок.md) передаётся без
изменений. Если встроенное исключение не распознано, `Классифицировать()`
возвращает `Неопределено`.

## Состав API

- [`КлассификаторНативныхОшибок`](КлассификаторНативныхОшибок.md) - фасад
  нормализации и расширение пользовательскими классификаторами и правилами.
- [`ПравилоКлассификацииНативныхОшибок`](ПравилоКлассификацииНативныхОшибок.md) -
  декларативное пользовательское правило.
- [`ФабрикаПравилНативныхОшибок`](ФабрикаПравилНативныхОшибок.md) - создание
  правила для конкретного способа сопоставления.
- [`СпособыСопоставленияНативныхОшибок`](СпособыСопоставленияНативныхОшибок.md) - именованные
  способы сопоставления для пользовательских правил.
- [`РаспознавательОшибки`](РаспознавательОшибки.md) - передаваемый
  пользовательскому классификатору контекст поиска типов и сообщений.
- [`КодыНативныхОшибок`](КодыНативныхОшибок.md) - именованные стабильные коды.

Поддерживаемые коды приведены в
[`КодыНативныхОшибок`](КодыНативныхОшибок.md).
