# Публичный интерфейс

Пакет `native-errors` преобразует ошибки встроенных объектов OneScript в
структурированные ошибки пакета `errors`. Машинный код результата можно получать
через `ДиагностикаОшибок.КодОшибки()` из пакета `errors`.

Подключение в прикладном модуле:

```bsl
#Использовать errors
#Использовать native-errors

Классификатор = Новый КлассификаторНативныхОшибок;

Попытка
    Чтение = Новый ЧтениеJSON;
    Чтение.Прочитать();
Исключение
    Ошибка = Классификатор.Классифицировать(ИнформацияОбОшибке());
    Если Ошибка <> Неопределено Тогда
        Сообщить(ДиагностикаОшибок.КодОшибки(Ошибка));
    КонецЕсли;
КонецПопытки;
```

Нормализованная ошибка передаётся без изменений. Если встроенное исключение не
распознано, `Классифицировать()` возвращает `Неопределено`.

## Состав API

- [КлассификаторНативныхОшибок](КлассификаторНативныхОшибок.md) - фасад
  нормализации и расширение пользовательскими классификаторами.
- [РаспознавательЦепочкиОшибок](РаспознавательЦепочкиОшибок.md) - поиск типа и
  сообщений во вложенной цепочке причин.
- [КодыНативныхОшибок](КодыНативныхОшибок.md) - именованные стабильные коды.

Встроенные классификаторы обрабатывают ошибки файловой системы, потоков, JSON,
XML, текста, двоичных данных и HTTP. Точный набор кодов доступен в модуле
`КодыНативныхОшибок`.
