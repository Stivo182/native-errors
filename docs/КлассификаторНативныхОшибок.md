# КлассификаторНативныхОшибок

Классифицирует исключения встроенных объектов OneScript в нормализованные ошибки
пакета [`errors`](https://github.com/Stivo182/oscript-errors).

## Создание

```bsl
Новый КлассификаторНативныхОшибок
```

Создаёт классификатор кодов из [`КодыНативныхОшибок`](КодыНативныхОшибок.md): файловой системы, JSON,
XML, двоичных данных, преобразований типов, даты, фоновых задач, объектов,
свойств, вызовов, таблиц, коллекций, текста, URL, потоков, HTTP, прокси и сети.

## Методы

### ДобавитьПользовательскийКлассификатор

```bsl
.ДобавитьПользовательскийКлассификатор(<Классификатор>)
```

Добавляет пользовательский классификатор перед встроенными.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Классификатор | Произвольный | Объект с экспортным методом `Классифицировать(Ошибка, Распознаватель)`. |

Метод пользовательского классификатора возвращает `ИнформацияОбОшибке`, если
правило применимо, или `Неопределено`, чтобы продолжить поиск.

Распознаватель создаётся библиотекой. Доступные методы поиска описаны в разделе
[`РаспознавательОшибки`](РаспознавательОшибки.md).

Пользовательские классификаторы вызываются в порядке добавления и раньше
встроенных. Исключение: корневая ошибка с кодом из [`КодыНативныхОшибок`](КодыНативныхОшибок.md)
возвращается без вызова классификаторов.

#### Возвращаемое значение

Этот [`КлассификаторНативныхОшибок`](КлассификаторНативныхОшибок.md) для цепочки вызовов.

### ДобавитьПравила

```bsl
.ДобавитьПравила(<Правила>)
```

Добавляет декларативные пользовательские правила после пользовательских
классификаторов и до встроенных правил.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Правила | `Массив` из [`ПравилоКлассификацииНативныхОшибок`](ПравилоКлассификацииНативныхОшибок.md) | Пользовательские правила. |

Правила копируются при добавлении, поэтому последующее изменение объектов правил
не влияет на классификатор.

Источник правил в данных результата устанавливается автоматически в
`ПользовательскиеПравила`.

#### Возвращаемое значение

Этот [`КлассификаторНативныхОшибок`](КлассификаторНативныхОшибок.md) для цепочки вызовов.

### Классифицировать

```bsl
.Классифицировать(<Ошибка>)
```

Возвращает нормализованную ошибку или не определяет код, если подходящего
классификатора нет.

Нормализованная корневая ошибка с кодом из [`КодыНативныхОшибок`](КодыНативныхОшибок.md) возвращается
без изменений. В остальных случаях пользовательские классификаторы имеют
приоритет. Собственный структурированный код в причине имеет приоритет над
декларативными текстовыми правилами. Встроенные правила проверяются по всем
кадрам причины: более надёжный признак побеждает, одинаковые коды объединяются,
а равносильные разные коды дают `Неопределено`.
Чужой структурированный код исключает встроенные текстовые правила только для
своего кадра; вложенные причины продолжают анализироваться.

#### Параметры

| Параметр | Тип | Описание |
| --- | --- | --- |
| Ошибка | `ИнформацияОбОшибке` | Исходная нативная или уже нормализованная ошибка. |

#### Возвращаемое значение

`ИнформацияОбОшибке` с нормализованным кодом либо `Неопределено`.
