# Способы сопоставления нативных ошибок

Модуль возвращает идентификаторы способов для поля `Способ` объекта
[`ПравилоКлассификацииНативныхОшибок`](ПравилоКлассификацииНативныхОшибок.md).

| Функция | Сопоставление |
| --- | --- |
| `Точное()` | Полное сообщение. |
| `Префикс()` | Начало сообщения. |
| `ПрефиксОкончание()` | Начало и окончание сообщения. |
| `ПоТипу()` | Нативный тип. |
| `ТипИОкончание()` | Нативный тип и окончание сообщения. |
| `ТипИФрагмент()` | Нативный тип и фрагмент сообщения. |
| `ТипИОбрамление()` | Нативный тип, фрагмент и окончание сообщения. |
